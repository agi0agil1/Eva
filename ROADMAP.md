# Дорожная карта

1. Сад решений: локальный интерактивный этюд.
2. Проверка с добровольцами: понятность без инструкции, ощущение причинности, доступность.
3. Экспорт и повторное воспроизведение истории; автоматические тесты переходов.
4. Второй этюд: персонажи с различимыми целями и ограничениями.
5. Опциональный адаптер языковой модели с явным согласием и лимитами ресурсов.
6. Публичная веб-демонстрация после проверки.

Критерий успеха — качество опыта, а не количество функций. Развёртывание, лицензия и подключение платных API требуют отдельных решений.
