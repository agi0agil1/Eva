# ЕВА

**Интеллект как искусство.**

ЕВА — публичный русскоязычный эксперимент по созданию нового опыта взаимодействия человека и искусственного интеллекта. Простота снаружи, глубина внутри.

Первый этюд — «Сад решений»: небольшое интерактивное пространство, где выбор меняет состояние мира и оставляет причинный след. Это не подключённая языковая модель, а детерминированный художественный прототип.
